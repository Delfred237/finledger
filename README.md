# FinLedger CLI

Personal budget management CLI built with native Java.

## Status

Early development.  
This repository currently contains the initial Maven project skeleton.

## Goal

The goal of this project is to demonstrate solid Java fundamentals through a real command-line application:

- object-oriented design;
- clean separation of concerns;
- validation;
- error handling;
- collections;
- streams;
- `BigDecimal` for money;
- Java Time API;
- local persistence;
- unit testing.

This project is intentionally built without Spring Boot, Hibernate, JPA, external database, REST API, or frontend, in order to focus on native Java.

## Tech Stack

- Java 21
- Maven
- JUnit 5
- Git

## Requirements

- JDK 21 or newer
- Maven 3.9+
